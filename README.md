# Security Research Data

A collection of CSV files covering publicly reported security incidents, malware campaigns, threat actors, vulnerabilities and related indicators of compromise (IOCs).

## Dataset contents

The collection includes records referring to:

- Threat actor groups and activity clusters
- Malware families, loaders, RATs and ransomware
- Phishing and social-engineering campaigns
- Indicators of compromise and infrastructure
- Vulnerability-related activity and public exploit reporting

## Format

Each topic is stored in a separate CSV file. Schemas may vary between files because the records originate from different reports and collections.

## Using the data

Treat the files as research material rather than a live threat feed. Validate indicators against current sources before using them in detection rules, blocklists or incident-response workflows. Historical IOCs can become stale, reassigned or harmless over time.

## Scope

This repository is a data collection. It is not a guarantee that every entry is complete, current or independently verified, and it should not be treated as a source of executable exploit code.
